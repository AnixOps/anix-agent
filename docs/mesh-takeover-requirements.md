# 组网：接管、导入、无 Agent 部署与只读上报需求

状态：需求已确认（2026-11-25），尚未实现。编号沿用项目需求表（R1–R34）。组网模块本身在内核中实现；本页是 Agent 与部署层负责的部分。

## 接管已有节点（R12）

- 适用于 macOS、Windows、Linux、OpenWrt 上的完整节点。
- 启动组网前检测本机是否运行现有组网程序的进程或系统服务；有服务则先停用开机自启，再停止进程，然后由组网模块接管同一网络。
- 原程序文件与配置不删除，可回滚：停止组网模块并恢复原服务即回到迁移前状态。
- 现有组网程序的识别信息（进程名、服务名、配置路径）作为部署层数据维护，不写进内核与客户端界面。

## 自动导入配置（R13、R15）

- 单向转换，只取互通需要的信息：网络名、密钥、对端地址、通告子网、虚拟地址、监听端口。
- 有风险或不支持的设置不导入，例如放宽的管理端口、出口、端口转发、远程配置服务器。
- 每次导入生成报告，逐项列出已转换、已丢弃与需人工确认的内容。
- 第一版不自动迁移使用子网映射或接入远程配置服务器的节点，标为「无法自动迁移」。
- 现有程序节点若使用自动分配地址，导入时一律改为固定地址（R29）。

## 无 Agent 机器的部署（R31、R32）

- 面板为节点签发一次性入网凭据，用过即作废，之后使用节点自己的设备密钥。
- 一条安装命令完成：下载并校验签名的组网程序、注册系统服务、执行上述接管与导入、凭凭据领取地区、固定地址与密钥后入网。
- 卸载命令恢复原程序（回滚）。
- 平台：Linux（systemd / OpenRC）、OpenWrt（软件包 + procd）、Windows（系统服务）、macOS（launchd）。
- 接管、导入与上报做成组网程序的子命令，Agent 与安装命令调用同一份，逻辑只维护一处。

## 只读上报（R31）

- 无 Agent 节点向面板只读上报在线状态与延迟，不接受面板下发的指令，不开监听端口。
- 中国大陆地区的上报与 Agent 连接经地区中继（R33、R34，见对应 PR）。
